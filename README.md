演奏用MML変換

MIDIファイルを演奏用MMLに変換するツールです。
インストールは不要で、インターネット接続だけで動きます。

使い方
1. https://werebaize80.github.io/ensou-mml/ をブラウザで開きます。
2. .mid / .midi ファイルを画面にドロップします。
3. クオンタイズ、使える音数、メロディの下限を選びます。
4. パートのボタンでコピーするか、「MMLを保存」でファイルに保存します。

補足
- 動作にはChromeやEdgeなどの新しいブラウザが必要です。
- 1パートの上限は2400字として確認しています。
- 途中のテンポ変更は反映せず、最初のテンポで出力します。
- 読み込んだファイルは外部に送信されません。
